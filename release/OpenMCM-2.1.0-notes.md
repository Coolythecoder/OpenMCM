# OpenMCM 2.1

Package/build version: 2.1.0. This release naming update retains the previous
slider-storage repair, acknowledged Kicker reset, full FOMOD and source/licence
packaging. It does not add or change gameplay behavior.

- Native release metadata, installer version, documentation and corresponding
  source archives are rebuilt consistently as 2.1.0.
- Full unmodified GPL v3 text remains in LICENSE.txt and LICENSE. Copyright and
  GPL/warranty notices remain in README.txt; third-party boundaries are retained.
- Full editable project source, build scripts, tests, plugin YAML and pinned
  CommonLibSSE-NG/dependency sources are included in source/OpenMCM-2.1.0-Source.zip.
- No private memory dumps, tool caches or extracted game assets in source.
- SkyUI MCM API remains 4, OpenMCM extension API remains 1, and Field Guide
  remains 1.0.0. Save migration/provider versions are unchanged.

The slider-storage repair and optional Kicker adapter still need in-game
confirmation. Automated checks are not gameplay verification or Nexus approval.
Nexus page updates and moderation review remain separate from building this ZIP.
