SOURCE AND BUILDING

Full editable project source is included in source/OpenMCM-2.1.0-Source.zip.
It contains the MCM ActionScript and Papyrus, both native modules, plugin YAML,
examples, build scripts, tests, and pinned CommonLibSSE-NG/dependency sources.
Read BUILD-SOURCE.txt inside for instructions and prerequisites. The builder
must supply a legally installed Skyrim copy for the vanilla Journal asset;
extracted game assets are not part of the source archive. General-purpose
compiler/tool binaries, build caches and private diagnostics are not included.

The original browser module source archive is also retained in source/ for
its recorded provenance. OpenMCM_BUILD.json identifies and hashes both archives.
