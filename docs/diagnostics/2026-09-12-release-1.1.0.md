# OpenMCM 1.1.0 release validation

Built 12 September 2026 from the owner's local Skyrim 1.7.104.0 installation.
The owner confirmed working mouse input, text/colour, and every MCM in their
current mod list before promotion. See `../../COMPATIBILITY.md` and the
enabled-MCM inventory in this directory for the seven providers and evidence.

## Verification

Default `build.ps1` now selects 1.1.0. The final full build completed with:

- 354 source, 312 staged, and 449 packaged compatibility-contract checks.
- 193 Python tests: 192 passed, one opt-in workspace test skipped because
  `MCM_CONTRACT_TARGET` was unset during the build. The final ZIP was already
  explicitly checked by the build's release checker; the contract-checker suite
  was also rerun afterward with that environment variable pointing at the ZIP:
  all 28 tests passed, with no skips.
- 82 native precache regression cases plus x64 ABI assertions passed.
- Staged and packaged native PE/export/runtime/config validation passed.
- Final binary export and build JSON agree on numeric version `0x01010000`;
  compiled log string contains 1.1.0.
- Final ZIP README, compatibility and release notes match their authored
  sources. Local Markdown link targets in the packaged documents exist.
- No executable build tools, PDBs, logs, emulator fixtures, or node_modules
  are shipped. Mouse diagnostics remain opt-in/off by default in normal use.
- Independent archive review matched all 34 non-checksum files against the
  checksum inventory, found no uncovered/duplicate paths, and confirmed the
  final archive hash, version, contents and documentation.

The previously run native AVM1 text/mouse fixtures apply to the identical SWF;
they were not rerun during this metadata-only release promotion. The owner's
Skyrim confirmation is separate from those emulator checks.

## Limits

The compatibility list is owner-reported for the installed versions, not a
universal certification. No new in-game session was run for the metadata bump.
The optional native precache adjustment remains Skyrim 1.7.104.0-only and lacks
confirmed in-game fix verification. The separate exit-to-desktop crash is not
claimed fixed. Upgrade instructions preserve custom INI values and intentional
DLL omission and warn against simultaneous SkyUI or stale OpenMCM add-ons.
